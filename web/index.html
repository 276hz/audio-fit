How it works

Lossless formats such as FLAC already squeeze audio as far as it goes. A second pass typically saves under 1%. If a file is over a limit, no lossless trick makes it smaller.

So the app first measures, then tells you honestly: it fits, or it does not. When it does not, the lossless answer is to split the track at a quiet moment into parts that each fit. Cuts land on an exact sample.

After every run the app decodes what it produced, joins the parts and compares a SHA-256 hash of the audio samples with your original. Only an exact match is labelled bit-exact.

Privacy

Everything runs inside this page, in a background worker on your device. Audio, file names and tags are never uploaded or sent anywhere.

There is no tracking, no analytics, no ads and no account. The page only stores your language and theme choice in your browser, and only if storage is allowed. You can check the Network tab of your browser: after the page loads, there is no request that contains your data.

Licences and credits

This build contains no third-party codec or library. The FLAC reader and writer, the hash and the ZIP writer were written for this project following the public FLAC format specification. MP3, AAC and Opus export will need a codec engine; its licence terms will be listed here when it is added.

Frequently asked questions

Why can't my FLAC shrink to the limit?

FLAC is already compressed without loss. Lossless compression has a floor set by the music itself. Going below it requires removing information, which is lossy.

Is splitting really lossless?

Yes. The parts contain exactly the original samples. The report lists the hash that proves it. Check that your platform accepts multi-part releases.

Are the platform limits up to date?

Requirements change. Always check the platform's own page. Profiles marked unverified come from text you supplied, not from the platform's documentation.

How big a file can I use?

Decoded audio is held in memory, so very large files can fail, mostly on phones. The app tells you if a file is too big; use a computer in that case.

Requirements of other platforms may change; check their pages. Audio never leaves your device.
